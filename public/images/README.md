# Image Assets — journey.storage

## Folder Structure
- brand/ → logos (SVG), favicon, apple-touch-icon, og-image
- hero/ → home-hero-bg.jpg (main landing page hero background)
- moments/ → home-moments-moving.jpg, home-moments-newchapter.jpg, home-moments-business.jpg, home-moments-cityliving.jpg
- facility/ → home-facility-exterior.jpg, home-facility-interior-person.jpg (optional)
- team/ → home-jonah-portrait.jpg

## Naming Convention
[page]-[section]-[description].[ext]

## Formats
- Photos: .jpg or .webp (Next.js Image component handles format optimization)
- Logos: .svg (clean, no embedded rasters)
- Icons: .svg or .png (favicon at 32px, apple-touch at 180px)
